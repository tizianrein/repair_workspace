Workshop results — static snapshot
==================================

Served from   src/public/results/  ->  https://repair-workspace.vercel.app/results/
Project       example:timber_corner  (Cloudflare D1 + R2)
Exported      see data/exhibit.json -> meta.generatedAt
Contents      12 participant layers: parts models, conditions, strategies,
              steps with justifications, intent axes, evidence records.

Vite copies src/public/ into dist verbatim, so this folder ships with every
deploy and needs no build step of its own. The page reads data/exhibit.json and
the files in images/; it calls no backend at view time, so it keeps working if
the Worker, the database or the API keys go away.

app.css is the application's own stylesheet, copied unchanged, so the exhibit
reads as the same product the participants used. results.css holds only what
this read-only build adds on top. Do not edit app.css here: re-copy it from the
built bundle when the app's styles change.

Missing images
--------------
94 of 116 evidence files are absent. Their records carry url "idb://<id>",
meaning the bytes only ever existed in IndexedDB in the browser that made them:
photos reach R2 on one path, and renderings are never uploaded at all. Where an
image is missing the page shows the sollJson target state recorded beside it.

The scan
--------
model/mesh.glb is the photogrammetry scan reduced from 42 MB to 2.5 MB: texture
4096 PNG -> 2048 WebP, geometry simplified 420k -> 62k triangles, positions
quantised. No Draco or Meshopt decoder is needed. It loads only when a visitor
opens the Scan tab.

To refresh
----------
1. node export-workshop.mjs             (repo root)
2. recompile exhibit.json + images from exhibit-snapshot/
3. replace data/ and images/ here, commit, push. Vercel redeploys.
